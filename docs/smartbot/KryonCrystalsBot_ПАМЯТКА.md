## Продуктовая логика (коротко)

1. **Онбординг** — первый вход → уведомление менеджеру + строка в Sheets «Подписчики» → приветствие.
2. **`/practice_with_crystals`** — развилка: есть `%Email%` или сбор почты → выбор «Путь через Туман» (7/21/33) или маршруты под задачу.
3. **Путь через Туман** — оплата YooKassa → метка статистики → переменная (`%М7Д_КАК%` / `%М21Д_КАК%` / `%М33Д_КАК%` / `%М7_33Д_КАК%`) → список → дневные сообщения + `set_timer` на 19:00.
4. **Маршруты под задачу** — Простить / Отпустить (и заглушки на остальные) → 1 / 3 / 7 дней, оплата или заглушка «365 дней».
5. **Коды наклеек 3D** — `ANANASHA888`, `ARIS888`, … → счётчики + текст кристалла.
6. **Магазин колоды** — `/buy_deck` → portal в сценарий «🚚 Магазин в Telegram с доставкой (Крайон)».
7. **Default answer** — нет сценария → notify + Sheets «Сценарий не подошел».
