## «Сегодня» (inline)

| Кнопка | Поведение |
|--------|-----------|
| 👼 Ангельский знак | Инструкция; числа/время в чате → локальные справочники `data/angelic/*.csv` |
| 🃏 Карта дня | Инструкция → карта или кристалл на maranius.ru (1× за локальные сутки каждый; без часового пояса — по Москве) |
| 🎲 Бросить кубик | Telegram dice + текст дня |

Ангелы: писать **в любом месте** чата (`11:11`, `777`, `14:30`).

## Карта и кристалл дня

- Каталог: `data/daily_practice_catalog.json`
- Карта: `CARD_OF_DAY_BASE_URL` (по умолчанию `https://maranius.ru/practice/podskazki`)
- Кристалл: `CRYSTAL_OF_DAY_BASE_URL` (по умолчанию `https://maranius.ru/themes/kristally`); ссылка ведёт на якорь карточки `#<slug>`.

## Скрытая панель `/god` (только seed-админ)

| Раздел | Действия |
|--------|----------|
| Inbox | сводка записей за 90 дней и CSV inbox |
| Списки | CSV: бот доступен, заблокировали бота, согласия, безопасный сегмент «Готовы к рассылке», VIP-доступ, активность и стоп-лист |
| Пользователи | поиск по Telegram ID / @username, выдача и снятие VIP, ограничение и снятие ограничения; для любого действия нужны основание и подтверждение |
| Бот | сводка пользователей и служебный статус |
| VIP | сводка/CSV кодов; добавление кодов с предпросмотром и подтверждением, импорт VIP — с предпросмотром, основанием и подтверждением |
| Журнал действий | последние изменения, CSV аудита и журнала согласий за 365 дней |

«Готовы к рассылке» не запускает рассылку: это CSV-пересечение `marketing_opt_in`,
принятой политики, доступности бота, отсутствия ручного стоп-листа и `is_internal = false`.
Массовой отправки сообщений в `/god` нет.
