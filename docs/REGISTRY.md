# Реестр Maranius

Актуальная карта функций и служебных механизмов. Подробная карта кнопок: [ИНТЕРФЕЙС_МЕНЮ_И_КОМАНДЫ.md](./ИНТЕРФЕЙС_МЕНЮ_И_КОМАНДЫ.md).

**Боевой бот:** `@MaraniusBOT`, `BOT_PROFILE=prod`.

**Стенд:** `@angelic_signs_bot`, `BOT_PROFILE=test`.

## Команды Telegram

| Команда | Назначение | Статус |
|---------|------------|--------|
| `/start` | Запуск и главное меню; для нового пользователя — сначала согласие | **done** |
| `/store` | Каталог Maranius | **done** |
| `/learning` | Онлайн-курсы | **done** |
| `/contact` | Связь с автором | **done** |
| `/policy` | Политика и управление рассылкой | **done** |
| `/weather`, `/moon` | Погода и Луна; доступны также через «Ещё» | **done**, скрыты из меню `☰` |
| `/god` | Скрытая админ-панель | **done**, только seed-админ |

`/services` не используется: контакты открываются через `/contact`, услуги — через «Ещё → Услуги».

## Пользовательские разделы

| Раздел | Что работает | Статус |
|--------|----------------|--------|
| `✨ Сегодня` | Ангельские знаки, карта дня, кристалл дня, кубик | **done** |
| `🔑 Моё VIP` | Активация кода, запрос доступа, колоды, разделы и PDF | **done** |
| `🛒 Лавка` | Переход в каталог | **done** |
| `⋯ Ещё` | Погода, Луна, услуги, курсы, FAQ, политика | **done** |

Карта, кристалл и кубик выдаются один раз за локальные сутки пользователя. Часовой пояс определяется по сохранённой геолокации; без неё используется Москва.

## Надёжность и данные

- JSON записывается атомарно.
- Повреждённый JSON восстанавливается из последней валидной копии; повреждённый оригинал сохраняется.
- Необработанная ошибка даёт понятный ответ пользователю, пишется в журнал и отправляется админу.
- Деплой создаёт резервную копию рантайм-данных до обновления.
- Рантайм-файлы, `.env`, VIP-коды и Telegram `file_id` исключены из Git.

## Автоматические проверки

Workflow `.github/workflows/tests.yml` запускается:

- при каждом `push` в `main`;
- для pull request в `main`;
- вручную из GitHub Actions.

Проверяются unit-тесты, синтаксис Python и shell-скриптов. Секреты для тестов не нужны.

## Переменные `.env`

| Переменная | Назначение |
|------------|------------|
| `BOT_PROFILE` | `test` или `prod` |
| `BOT_TOKEN_TEST` | Токен стенда |
| `BOT_TOKEN_PROD` | Токен боевого бота |
| `TELEGRAM_PROXY_URL` | SOCKS-туннель на Hip prod; опционально |
