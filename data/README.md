# data

## О папке

Исходные справочники и материалы бота. Они хранятся в Git. Пользовательские и служебные JSON-файлы исключены через `.gitignore`.

## Содержимое

| Файл | Назначение |
|------|------------|
| `daily_practice_catalog.json` | Slug-каталог карт и кристаллов для ссылок на сайт |
| `dice_messages.json` | 30 текстов × 6 граней кубика; ротация по суткам MSK (`integrations/dice_content.py`) |
| `vip/` | VIP-колоды и PDF; рантайм-кэш `file_id` в Git не попадает |
| `angelic/` | Справочники ангельских знаков |

Пользовательские/тестовые файлы — по мере появления.

## Как использовать

Не класть сюда секреты продакшена без шифрования. Для прод-состояния — политика на сервере в `ИНСТРУКЦИЯ_ДЕПЛОЙ_БОТА.md`.
